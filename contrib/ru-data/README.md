# Русские базы: задания, достижения, предметы, имена мира

Готовые таблицы перевода, собранные для аддона **Ascension euRU - Tooltips** (оригинальные авторы
Kypcop и Jivayavarya, Area 52). Здесь лежат только данные — движка и кода из того аддона нет,
чтобы не тащить чужую лицензию в CoARU. Данные предлагаются как есть, встраивай как удобно.

Закрывает то, чего в CoARU пока нет: **тексты заданий**, достижения и имена NPC/объектов/зон.

## Пересечение с CoARU 1.0.2

Сверялся с текущим релизом, а не с README: распаковал `CoARU_CHUNK_EN` (7,4 млн символов
английского корпуса) и собрал `CoARU_ItemName` (39 536 названий по ID). Дальше выборка по
300 случайных записей из каждой базы — сколько из них у тебя уже есть:

| база | уже покрыто в 1.0.2 | новое |
|---|---:|---:|
| Задания | 2 % | ~98 % |
| Достижения | 1 % | ~99 % |
| Имена мира | 23 % | ~77 % |
| Строки предметов | 36 % | ~64 % |

По предметам оговорюсь честно: твой подход с ключом по item ID лучше моего строкового, названия
предметов у тебя объективно надёжнее. Из моих 73 715 строк примерно треть — это те же названия,
их можно просто выкинуть при импорте. Остаток — строки тултипа, требования и описания кастомных
предметов Ascension, которых в базе нет.

## Формат

Все файлы — обычный Lua. Таблица завёрнута в функцию, чтобы не висеть в памяти до вызова:

```lua
function loadQuestsData()
    TranslatedQuestsDescriptions = {
        ["Report to Zurai"] = "Донесение Зураю",
        ...
    };
end
```

Ключ — английская строка ровно в том виде, в каком её отдаёт сервер (для заданий — с учётом
пробелов и знаков, они нормализованы под текущую базу CoA). Значение — русский текст.
В текстах заданий сохранены оригинальные плейсхолдеры Blizzard (`$B`, `$N`, `$Gон:она;`).

Функции-обёртки под твой конвейер, конечно, не нужны: сдирается двумя строками, а дальше
таблицы прогоняются через твоё сжатие LibDeflate так же, как `CoARU_Data`.

## Откуда взяты переводы

Это важно для оценки качества, поэтому по-честному:

* **Официальная локализация Blizzard** — имена NPC/объектов/зон, названия и тексты классических
  и WotLK-заданий, названия предметов. Взяты из ruRU-клиента 3.3.5a и из официальных баз
  pfQuest. Это основная масса записей.
* **Машинный перевод (LLM)** — тексты заданий, достижений и предметов, которых в официальной
  локализации нет в принципе: контент Conquest of Azeroth и кастом Ascension. Собирались с
  `db.ascension.gg` и переводились пакетно. Вычитано выборочно, ошибки местами есть.

Если нужно разделить одно от другого — скажи, отдам данные с пометкой источника у каждой записи.

## Грабли, на которые уже наступили

**Строки интерфейса сюда не вошли осознанно.** Подмена глобалок из `GlobalStrings` (особенно
`ERR_*` и `SPELL_FAILED_*`) ломает игру: их читает защищённый код клиента, и в бою прилетает
taint с `ADDON_ACTION_BLOCKED`. Проверено на себе, поэтому в этой пачке только тултипные данные.

**Ключи заданий чувствительны к пробелам.** Сервер CoA местами отдаёт текст с HTML-entity
(`&nbsp;`, `&#39;`) и без пробела после точки. Ключи в файле уже нормализованы под то, что
реально приходит в `QuestFrame`, но при сверке со своей базой это стоит иметь в виду.

**Имена мира — на твоё усмотрение.** Ты сознательно оставил зоны и способности латиницей, и
логика понятная. `BigData_WorldNames_ru.lua` кладу отдельным файлом ровно поэтому: не хочешь —
просто не подключай, остальное от него не зависит.
